Critical utils/auth.py line 42

SQL injection in user lookup

User input is joined directly into a SQL string, so an attacker could read or change database records.

Suggested fix

Use a parameterized query: cursor.execute(query, (user_id,)).

High services/orders.py line 118

Possible division by zero

The average order value is calculated without checking whether the order count is zero.

Suggested fix

Return 0 early when order_count == 0.

Medium api/routes.py line 76

File handle never closed

The export route opens a file without closing it, which can leak resources under heavy use.

Suggested fix

Wrap the call in with open(...) as f:.
